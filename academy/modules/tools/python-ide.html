Python IDE – Hilfe

Hier läuft echtes Python 3 (Pyodide, WebAssembly) direkt in deinem Browser. Es gibt keinen Server und nichts wird hochgeladen.

Arbeiten

  • Ausführen: F5 oder Strg+Enter startet die aktuelle Datei als __main__. Andere Dateien kannst du importieren: from utils import add.
  • Tests: der Knopf „Tests“ führt alle Dateien test*.py mit unittest aus. Rot heißt wirklich rot.
  • Eingaben: input() liest Zeilen aus dem Feld „⌨ Eingaben“.
  • Shell: eigene Sitzung mit Speicher, Pfeil hoch/runter blättert den Verlauf.
  • Projekte: „📁 Projekte“ verwaltet mehrere Projekte, legt Vorlagen an (Daten, Scraper, Spiel, Excel), speichert Snapshots und erzeugt einen Link zum Teilen. Dateien dürfen in Ordnern liegen (ordner/datei.py); ein ZIP über „⬆ Hochladen“ wird entpackt.
  • Aufgaben: „🎯 Aufgaben“ bietet zehn Übungen mit automatischer Prüfung. „🤖 KI-Hilfe“ erklärt Fehler und Code in einfachen Worten.
  • Pakete: bekannte Pakete wie numpy oder pandas werden beim import automatisch nachgeladen. Weitere per import micropip und await micropip.install("paket") (reine Python-Pakete).
  • Diagramme: plt.show() zeigt matplotlib-Diagramme direkt in der Ausgabe.
  • Asynchron: await funktioniert auf oberster Ebene, asyncio.run(main()) wird automatisch angepasst.
  • Netzwerk: from pyodide.http import pyfetch mit await pyfetch(url) ruft Webadressen ab (der Server muss Browser-Zugriff erlauben).
  • Bibliothek: from vibe import * bringt rund 70 fertige Funktionen (Text, Finanzen, deutsche Feiertage, Datenanalyse, Sudoku, Graphen, KI-Abfrage, Diagramme). Der Knopf „📚 Bibliothek“ zeigt alle mit Beispielen.
  • Automatisch: importierst du ein Paket aus dem Katalog (z. B. openpyxl), das Python nicht mitbringt, wird es beim Ausführen von PyPI nachinstalliert.
  • Pakete: der Knopf „📦 Pakete“ installiert Bibliotheken per Namen, lädt eigene ZIP- oder Wheel-Dateien hoch (bleiben gespeichert) und zeigt einen Katalog mit Download-Pfaden. Mit einer Datei requirements.txt werden Pakete beim Start automatisch installiert.
  • Speichern: alles wird automatisch in deinem Browser gespeichert (localStorage), nichts verlässt dein Gerät.

Grenzen

  • Keine Server (Flask, FastAPI), keine Sockets und keine Threads (threading, socket, requests): der Browser erlaubt das nicht.
  • Endlosschleifen beendest du mit „■ Stopp“.
  • Dateien existieren nur in der IDE, nicht auf deiner Festplatte. Mit „Download“ und „Hochladen“ tauschst du sie aus.
