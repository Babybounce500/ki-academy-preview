⚡Stripe API Quickstart

Base URL: https://api.stripe.com/v1/ (HTTPS required)

Auth: HTTP Basic Auth – Username: your sk_…, leave password blank

Connect: Add header: Stripe-Account: acct_…

RAK/OAuth: Restricted API Keys or OAuth tokens for marketplaces
