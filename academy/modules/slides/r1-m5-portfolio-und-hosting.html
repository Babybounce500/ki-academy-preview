Eine gute Projektbeschreibung

Schwach

  • Eine To-do-App
  • Keine Technik genannt
  • Kein Ergebnis, kein Link

Stark

  • Welches Problem wird gelöst und für wen
  • Welche Technik wurde eingesetzt
  • Was kann man im Browser ausprobieren
  • Link zum Projekt

Was ist statisches Hosting?

Statisch

  • HTML, CSS, JavaScript und Bilder
  • Dateien werden einfach ausgeliefert
  • Günstig oder kostenlos möglich
  • Ideal für Portfolios

Mit Server

  • Logik und Datenbank im Hintergrund
  • Login, Zahlungen, Nutzerdaten
  • Mehr Aufwand und Sicherheitspflichten
  • Thema der Reihen 2 und 3

Veröffentlichen mit GitHub Pages

  1. 1
    Konto anlegen

    Auf github.com, mit starkem Passwort und Zwei-Faktor-Anmeldung

  2. 2
    Repository erstellen

    Zum Beispiel "mein-portfolio", öffentlich

  3. 3
    Dateien hochladen

    index.html, CSS, JavaScript und Bilder

  4. 4
    Pages aktivieren

    In den Einstellungen Veröffentlichung aus dem Hauptzweig wählen

  5. 5
    Adresse testen

    Seite im Browser und auf dem Handy öffnen

Alternativen für statisches Hosting

  • ✓GitHub Pages: nah am Code, ideal zum Lernen
  • ✓Netlify: Dateien per Ziehen und Ablegen veröffentlichen
  • ✓Cloudflare Pages: schnelle Auslieferung, Anbindung an Git
  • ✓Vercel: beliebt für Web-Apps und Frameworks
  • ✓Konditionen und Gratis-Kontingente vorab beim Anbieter prüfen

10 / 14

Rechtliches für öffentliche Seiten

  • ✓Impressum: bei geschäftsmäßiger oder beruflicher Nutzung nötig
  • ✓Datenschutzerklärung: wenn Daten verarbeitet werden, zum Beispiel Formulare oder Schriften von fremden Servern
  • ✓Eigene oder lizenzierte Bilder und Texte verwenden
  • ✓Schriften lokal einbinden statt von fremden Servern laden
  • ✓Keine Rechtsberatung: Muster prüfen lassen
