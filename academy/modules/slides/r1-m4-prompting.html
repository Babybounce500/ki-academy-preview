Prompting für Entwickler

Modul 4: KI präzise steuern, Code prüfen, Ergebnisse verbessern

02 / 13

Lernziele

  • ✓Einen Prompt in fünf Bausteine zerlegen
  • ✓Code erklären, korrigieren und verbessern lassen
  • ✓KI-Antworten prüfen, statt sie zu glauben
  • ✓Datenschutz im Umgang mit KI beachten
  • ✓Eine eigene Prompt-Bibliothek anlegen
03 / 13

Die fünf Bausteine eines Prompts

  1. 1
    Rolle

    Wer soll die KI sein, zum Beispiel erfahrener Webentwickler

  2. 2
    Kontext

    Wofür ist es, für wen, welche Technik

  3. 3
    Aufgabe

    Genau eine klare Aufgabe

  4. 4
    Format

    Wie soll die Antwort aussehen

  5. 5
    Grenzen

    Was nicht gebaut oder verändert werden soll

04 / 13

Beispiel mit allen Bausteinen

text
Du bist ein erfahrener Webentwickler.
Ich baue eine Portfolio-Seite für Selbstständige in HTML und CSS.
Aufgabe: Erstelle einen Kopfbereich mit Name, Beruf und Kontakt-Button.
Format: Nur der Code, danach drei Sätze Erklärung.
Grenzen: Keine externen Bibliotheken, keine Bilder.

Rolle, Kontext, Aufgabe, Format, Grenzen.

05 / 13

Wie du Ergebnisse verbesserst

Schlecht

  • Alles neu machen lassen
  • Mehrere Änderungen auf einmal
  • Nur "geht nicht" schreiben

Gut

  • Eine Änderung pro Runde
  • Fehler und Erwartung beschreiben
  • Das Unveränderte ausdrücklich schützen
06 / 13

Prompt: Fehler beheben

text
Beim Klick auf den Filter-Button werden alle Karten ausgeblendet.
Erwartet: Nur Karten der gewählten Kategorie bleiben sichtbar.
Hier ist mein Code: [Code einfügen]
Finde die Ursache, ändere nur das Nötige und erkläre die Korrektur in zwei Sätzen.

Was passiert, was erwartet wird, wie die Antwort aussehen soll.

07 / 13

Prompt: Code überprüfen lassen

text
Prüfe diesen Code auf Lesbarkeit, Barrierefreiheit und häufige Fehler.
Gib eine Liste mit den fünf wichtigsten Verbesserungen, nach Wichtigkeit sortiert.
Ändere den Code noch nicht.
[Code einfügen]

Erst bewerten lassen, dann gezielt umsetzen.

08 / 13

Prompt: Portfolio-Bausteine entwerfen

text
Ich baue ein Software-Portfolio mit drei Projekten.
Entwirf für jede Projektkarte: Titel, ein Satz Problem, ein Satz Lösung,
eingesetzte Technik und ein Ergebnis, das man im Browser prüfen kann.
Nutze nur Angaben, die ich dir gebe: [Projektangaben einfügen]

Die KI strukturiert, du lieferst die Fakten.

09 / 13

KI-Antworten prüfen

  • ✓Immer im Browser testen, nicht nur lesen
  • ✓Unbekannte Begriffe nachfragen und nachschlagen
  • ✓Bei Fakten nach Quellen fragen und selbst prüfen
  • ✓Sicherheit: Keine Schlüssel oder Passwörter im Code akzeptieren
  • ✓Bei Zweifel eine zweite Frage stellen: Was könnte hier schiefgehen?
10 / 13

Datenschutz beim Prompten

Nicht senden

  • Passwörter, Schlüssel, Zugangsdaten
  • Personenbezogene Daten von Kunden
  • Vertrauliche Firmeninterna
  • Verträge im Klartext

Besser

  • Beispieldaten mit erfundenen Namen
  • Ausschnitte statt ganzer Dateien
  • Platzhalter für Sensibles
  • Firmenregeln zu KI-Tools beachten
