# KI-Academy Vorschau

Prototyp zum Live-Testen: Kursbereich (Academy), Slides mit Live-Code, Prompt-Bibliothek und Landingpage.

- `academy/`: Kursbereich als Tab-Workspace mit Reihe 1 bis 3, Tools und Slides
- `product/`: Landingpage
- `release-slides/`: PDFs, Präsentationen (HTML mit Live-Code und Sprechernotizen), Notizen, Prompt-Bibliothek

Start: `index.html` im Browser öffnen oder die GitHub-Pages-Adresse dieses Repositories aufrufen.

## Hinweise
- Prototyp: Platzhalter, Termine und Checkout-Links sind noch nicht gefüllt.
- Einige Tools sprechen externe KI-Schnittstellen an und funktionieren nur, solange diese erreichbar sind.
- Alle Rechte vorbehalten. Es wird keine Lizenz zur Weiterverwendung erteilt.
