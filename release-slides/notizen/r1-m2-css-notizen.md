## Folie 2: Lernziele (bullets)
Fünf Ziele, am Ende überprüfbar in der Übung: eine gestaltete, responsive Seite.

## Folie 3: Dein erstes CSS: live (live)
Das Muster erklären: Wen wähle ich aus, welche Eigenschaft ändere ich, auf welchen Wert. Live Server oder Browser-Vorschau nutzen, damit Änderungen sofort sichtbar sind.

## Folie 4: Wo steht das CSS? (compare)
Für Projekte empfehlen wir die eigene Datei. Zum Ausprobieren ist das style-Tag völlig in Ordnung.

## Folie 5: Das Box-Modell (steps)
Jedes Element ist eine Box mit diesen vier Schichten. Wer das verstanden hat, versteht 80 Prozent aller Layoutfragen. Im Browser-Inspektor die Box eines Elements sichtbar machen.

## Folie 6: Layout mit Flexbox: live (live)
Flexbox ordnet Elemente entlang einer Linie an. Ideal für Menüs, Kartenreihen und Zentrierungen. Die Eigenschaften einzeln ändern und die Wirkung beobachten.

## Folie 7: Flexbox oder Grid? (compare)
Faustregel: Flexbox für Inhalte in einer Linie, Grid für das Gesamtraster. Beides lässt sich kombinieren. Die KI kann beide Varianten für dieselbe Seite schreiben, ein guter Vergleichsprompt.

## Folie 8: Responsive: Anpassung ans Handy, live (live)
Responsive heißt, dass dieselbe Seite auf jedem Gerät gut aussieht. Zuerst für das Handy denken, dann für größere Bildschirme erweitern. Im Browser die Fensterbreite ändern und beobachten.

## Folie 9: Dunkelmodus (code)
Variablen machen Design pflegbar. Ein Beispiel, das Teilnehmende sofort sehen: Betriebssystem auf Dunkel umstellen und die Seite folgt.

## Folie 10: Wenn CSS nicht tut, was du willst (steps)
Die häufigste Frage von Einsteigern: Warum wirkt meine Regel nicht? Praktisch zeigen, wie der Inspektor die Antwort liefert. Inline-Styles und !important als Notlösung erwähnen, nicht als Standard.

## Folie 11: Tailwind CSS: Gestalten per Klasse (title-image)
Kurz halten. Tailwind wird in den Kursmaterialien als Option gezeigt. Wer CSS versteht, versteht auch Tailwind. Umgekehrt ist es schwerer.
