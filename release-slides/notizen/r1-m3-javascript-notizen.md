# Sprechernotizen: Reihe 1, Modul 3: JavaScript

## Folie 1: JavaScript: deine Seite wird interaktiv (cover)
Bild: Das Haus bekommt Technik, Licht per Schalter, Klingel, Heizung. JavaScript macht Seiten lebendig. Ziel: kleine, nützliche Funktionen, die ins Portfolio passen.

## Folie 2: Lernziele (bullets)
Am Ende dieses Moduls entstehen zwei Funktionen fürs Portfolio: ein Dunkelmodus-Schalter und ein Filter für Projektkarten.

## Folie 3: Variablen und Funktionen: live (live)
const für Werte, die sich nicht ändern. Funktionen sind benannte Rezepte. Mit F12 die Konsole öffnen und das Ergebnis zeigen. 800 minus 5 Prozent sind 760.

## Folie 4: Auf Klicks reagieren: Dunkelmodus (live)
Das Grundmuster fast jeder Interaktion: Element auswählen, Ereignis abonnieren, etwas verändern. Mit einer CSS-Klasse .dunkel aus Modul 2 verbinden.

## Folie 5: Einstellungen merken (code)
localStorage speichert kleine Texte im Browser des Besuchers. Nicht für sensible Daten. Hier ideal für Einstellungen wie Dunkelmodus.

## Folie 6: Projektkarten filtern: live (live)
Genau dieses Muster nutzt ihr in Modul 5 im Portfolio. Zuerst nur im Kleinen mit drei Karten ausprobieren.

## Folie 7: Fehler finden mit der Konsole (steps)
Fehlermeldungen sind Wegweiser. Gemeinsam eine typische Meldung lesen, zum Beispiel Cannot read properties of null, und die Ursache klären: Element wurde nicht gefunden.

## Folie 8: Prompt: JavaScript erklären lassen (code)
Teilnehmende sollen Code, den sie nicht verstehen, nie einbauen. Diese Frage kostet 20 Sekunden und verhindert Stunden Fehlersuche.

## Folie 9: Daten von einer Schnittstelle laden (code)
Ein Ausblick: Das Portfolio kann seine Projekte aus einer Datei laden, so muss man den Code nicht für jedes neue Projekt ändern. Das ist der erste Schritt zu dynamischen Seiten.

## Folie 10: Was ins Frontend darf (compare)
Wichtigste Sicherheitsregel: Alles im Frontend kann jeder lesen, auch über Quelltext anzeigen. Geheime Schlüssel gehören auf einen Server. Das vertiefen wir in Reihe 2.

## Folie 11: Quiz (quiz)
Sehr wichtig. Wer die Regel einmal verstanden hat, vermeidet einen der teuersten Anfängerfehler.

**Loesung:** C - Der Quelltext einer Webseite ist für jeden lesbar. Geheimnisse gehören auf einen Server.

## Folie 12: Übung: Zwei Funktionen für dein Portfolio (steps)
40 Minuten. Die Ergebnisse werden in Modul 5 ins Portfolio eingebaut. Wer festhängt, nutzt den Coding-Chatbot oder den Live-Call.
