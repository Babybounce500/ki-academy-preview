04 / 12

Was du brauchst

Nötig

  • Ein Computer der letzten Jahre mit aktuellem System
  • Ein moderner Browser
  • Ein Texteditor oder der Online-Editor im Kursbereich
  • Zugang zu einem KI-Assistenten

Nicht nötig

  • Programmiererfahrung
  • Teure Hardware
  • Installation vieler Programme
  • Englisch auf Expertenniveau
05 / 12

Dein Arbeitsplatz

  • ✓Browser: Chrome, Firefox, Edge oder Safari
  • ✓Editor: Visual Studio Code oder der Online-Editor im Kursbereich
  • ✓Ein Projektordner mit sprechenden Namen, zum Beispiel "mein-erstes-projekt"
  • ✓Vorschau: Seite im Browser öffnen und mit F5 neu laden
06 / 12

So arbeitet man mit KI beim Lernen

  1. 1
    Aufgabe verstehen

    Erst selbst überlegen, was du erreichen willst

  2. 2
    Prompt schreiben

    Ziel, Rahmen und gewünschte Erklärung nennen

  3. 3
    Ergebnis testen

    Immer im Browser öffnen, nicht nur lesen

  4. 4
    Nachfragen

    Alles, was du nicht verstehst, erklären lassen

  5. 5
    Selbst ändern

    Eine Kleinigkeit anpassen, um zu prüfen, ob du es verstanden hast

08 / 12

Gute und schlechte Lernprompts

Schwach

  • Erklär mir Programmieren
  • Mach das für mich
  • Keine Zielgruppe, kein Umfang

Stark

  • Erkläre X für Einsteiger mit einem Beispiel
  • Zeige den Code und erkläre jede Zeile
  • Nenne einen typischen Fehler dazu
