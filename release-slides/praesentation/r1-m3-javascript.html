05 / 12

Einstellungen merken

javascript
const gespeichert = localStorage.getItem('modus');
if (gespeichert === 'dunkel') {
  document.body.classList.add('dunkel');
}

function umschalten() {
  const istDunkel = document.body.classList.toggle('dunkel');
  localStorage.setItem('modus', istDunkel ? 'dunkel' : 'hell');
}

Der Browser merkt sich die Wahl, auch nach dem Neuladen.

Daten von einer Schnittstelle laden

javascript
async function ladeDaten() {
  const antwort = await fetch('daten.json');
  const projekte = await antwort.json();
  console.log(projekte);
}

ladeDaten();

Hier liest die Seite eine eigene Datei. Später können es fremde Schnittstellen sein.

10 / 12

Was ins Frontend darf

Erlaubt

  • Anzeige und Interaktion
  • Eingaben prüfen, bevor sie gesendet werden
  • Kleine Einstellungen im Browser speichern
  • Öffentliche Daten abrufen

Niemals

  • Passwörter und geheime Schlüssel im Code
  • API-Keys von KI-Diensten
  • Zugangsdaten zu Datenbanken
  • Alles, was nur du sehen darfst
